# Redundis Sprite Cutter

Windows program that splits a sprite sheet into separate pictures.

## Download

Open the latest Release and download `Redundis-Sprite-Cutter-Windows.zip`.

Unzip it, then double-click `Redundis Sprite Cutter.exe`. Python is not required.

Windows may show a SmartScreen notice the first time, because the file is not signed yet. Choose More info, then Run anyway.
